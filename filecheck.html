FILECHECK.

Un programma concreto: verifica se un file corrisponde all'originale, calcola la sua impronta SHA-256 e trova copie identiche, senza caricare documenti sul web.

SHA-256Elaborazione localeSenza accountGratuito

1. Seleziona i tuoi file

Seleziona i file, calcola la loro impronta SHA-256 e confronta i risultati. L'operazione avviene nel browser, senza trasferire i documenti.

Trascina qui i file oppure selezionali

PDF, foto, archivi ZIP, documenti e altri file.

Scegli i file
FileDimensioneSHA-256Azione

2. Verifica un'impronta originale

Hai ricevuto il codice SHA-256 da una fonte attendibile? Incollalo qui e confrontalo con il primo file calcolato. Un codice uguale indica che i contenuti corrispondono con altissima affidabilità.

3. File identici nell'elenco

Selezionando più file puoi individuare contenuti identici anche quando i nomi sono differenti. Questa funzione non cancella e non modifica nulla.

FileCheck calcola impronte SHA-256 per verificare la corrispondenza dei contenuti e riconoscere copie identiche. Questa funzione non esegue analisi antivirus: per stabilire se un file contiene software dannoso serve un controllo di sicurezza distinto.

Limite operativo: 80 MB per file e 25 file per sessione, per evitare consumi eccessivi di memoria su smartphone. Se chiudi o aggiorni la pagina, i risultati vengono eliminati.
